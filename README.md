# 💄 GLAMORA – Beauty Store

Welcome to **GLAMORA**, a modern and responsive beauty store website designed to showcase makeup and skincare products with an attractive and user-friendly interface.

## ✨ Features

- **Responsive Navbar:** Easy navigation across website sections.
- **Hero Section:** Attractive banner with a background video.
- **Product Categories:** Eye Makeup, Lipstick, Highlighter, and Skincare.
- **Product Cards:** Display product names and prices.
- **Special Offers:** Promotional section featuring a 20% discount.
- **Add to Cart:** Buttons for adding products to the cart.
- **Contact Section:** Displays contact information.
- **Responsive Design:** Supports desktop, tablet, and mobile screens.
- **Modern UI:** Stylish black-and-pink theme.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3.8
- JavaScript

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Explore the GLAMORA Beauty Store website.

The objective of this project is to develop a visually appealing beauty store website and practise frontend development, responsive design, Bootstrap components, and JavaScript interactivity.
